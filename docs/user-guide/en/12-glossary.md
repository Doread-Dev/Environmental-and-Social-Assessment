# Glossary

<a id="glossary-terms"></a>
## Words ESMS uses

| Word | Meaning |
|---|---|
| **ESMS** | Environmental and Social Management System: this application. It guides a project through the environmental and social due diligence of AKF Syria, from the first screening to monitoring. |
| AKF | Aga Khan Foundation. ESMS exports use the AKF layout. |
| Tool 1 – **Screening** | the first look at a project: its risk category (A to F) and its potential negative and positive impacts. Submitted by the project team, approved or rejected by a reviewer. |
| Tool 2 – **Assessment** | the site-specific environmental assessment: the project and its setting, the legal requirements, the methods and consultations used, and a rating of 50 impact questions. Submitted and reviewed like the screening. |
| **SEMP** | Social and Environmental Management Plan: what the project will do about its impacts. In ESMS, Tools 3 and 4. |
| Tool 3 – **Management Activities** | the general environmental and social management activities of the project. |
| Tool 4 – mitigation plan | the specific measures that reduce each risk or increase each benefit (**Impact Mitigation & Enhancement Plan**). |
| Tool 5 – **Monitoring** | the values of the environmental and social indicators: a baseline and four quarters. |
| Risk category | the result of the screening: A **High Risk**, B **Low-Moderate Risk**, C **Negligible Risk**, D **Emergency**, E **Insufficient Info**, F **Positive Impact**. |
| Impact level | the rating of a question or an indicator: **Negligible**, **Low**, **Medium**, **High**, or **N/A** (not applicable). |
| **Total Project Impact** | the highest impact level found in the assessment's scoring. |
| Baseline | the value of an indicator before the project's work starts. |
| Editor | a user who enters data: Program Manager, Project Manager, Environmental Focal Point, Environmental Specialist, Administrator. |
| Reviewer | a user who approves or rejects Tools 1 and 2: Environmental Specialist, Administrator. |
| Draft | saved but not submitted yet; still editable. |
| Submit | send Tool 1 or Tool 2 to the reviewer. It is locked while it waits. |
| Approve | accept a submitted tool. It is final and the next tool opens. Recommendations are required. |
| Reject | send a submitted tool back to the team with a reason, to correct and submit again. |
| Archive | keep a project read-only and out of the project list. It can be restored. |
| **Library** | the organisation's guidance PDFs, the same for every project. |
| **Guidance** | the button on a tool page that opens the Library documents linked to that tool. |
| **Documents** | a project's own files, grouped by tool. |
| v3 | the next version of ESMS. Buttons marked **Available in v3** belong to it. |
