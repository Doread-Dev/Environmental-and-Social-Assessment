# دورك

لكل حساب دور واحد يختاره مدير النظام. ويحدد دورك الأزرار التي تراها: الزر الذي لا يحق لك
استخدامه لا يظهر أصلًا. وفي الإصدار الثاني يستطيع كل دور فتح كل المشاريع؛ لا يوجد خيار «مشاريعي
فقط».

يصف هذا الجزء ما يقوم به دورك.

<a id="role-users" data-requires="manage_users"></a>
## رعاية النظام ومستخدميه

بصفتك مدير النظام فأنت ترعى النظام والعاملين عليه:

- إنشاء الحسابات، وإعطاء كل حساب دورًا ومسمًّى وظيفيًا، وتغيير الأدوار، وتعطيل الأشخاص وإعادة
  تفعيلهم، وإعادة ضبط كلمات المرور المنسية. انظر [المستخدمون](10-administration.md#users).
- الإبقاء على حسابَي مدير نظام فعّالَين على الأقل. يرفض ESMS تعطيل آخر مدير فعّال أو إعطاءه دورًا
  آخر.
- الحذف النهائي للمشاريع المؤرشفة. انظر [الحذف النهائي](04-projects.md#project-purge).
- قراءة سجل النشاط **Activity log**: من حذف ماذا أو أرشفه أو استعاده أو استبدله، وكل تغيير على
  المستخدمين. انظر [سجل النشاط](10-administration.md#activity-log).

المكان: **Settings** (أسفل القائمة الجانبية)، التبويبان **Users & projects** و**Activity log**.

<a id="role-review" data-requires="approve"></a>
## مراجعة العمل

أنت مراجِع. تفحص عمل فرق المشاريع وتقرّر:

- اعتماد أو رفض الفرز المرسَل (الأداة 1) والتقييم المرسَل (الأداة 2). للاعتماد تكتب توصيات، وللرفض
  تذكر السبب. انظر [مراجعة الأداة 1](05-tool-1-screening.md#screening-review)
  و[مراجعة الأداة 2](06-tool-2-assessment.md#assessment-review).
- يحق لك اعتماد عملك أنت: لا يشترط ESMS شخصًا ثانيًا.

<a id="role-projects-admin" data-requires="archive_project"></a>
## أرشفة المشاريع وحذفها

تؤرشف المشاريع وتستعيدها، وتحذف المشروع الذي لم يُعتمد فيه شيء بعد. انظر
[الأرشفة والاستعادة](04-projects.md#project-archive) و[الحذف](04-projects.md#project-delete).
المكان: **Settings** ← **Projects Management**.

<a id="role-library" data-requires="manage_library"></a>
## العناية بالمكتبة

ترفع ملفات PDF الإرشادية للمؤسسة، وتختار أين تظهر، وتستبدلها أو تحذفها. انظر
[العناية بالمكتبة](09-library-and-guidance.md#library-manage).

<a id="role-project-work" data-requires="edit"></a>
## العمل على المشاريع

أنت تقوم بالعمل على المشاريع:

- إنشاء مشروع وإبقاء بياناته محدّثة. انظر [المشاريع](04-projects.md).
- ملء الأداة 1 (الفرز)، وحفظ المسودات، وإرسالها للمراجعة.
- بعد اعتماد الفرز، ملء الأداة 2 (التقييم) وإرسالها.
- بعد اعتماد التقييم، ملء الأداتين 3 و4 (أنشطة الإدارة وخطة التخفيف). وهما تُحفظان ولا تُرسَلان.
- بعد اكتمال الأداتين 3 و4، تسجيل بيانات الرصد في الأداة 5 كل ربع سنة.
- إذا رُفض عملك، قراءة السبب وتصحيح العمل وإرساله من جديد.
- رفع وثائق المشروع وحذفها في صفحة **Documents** الخاصة به.
- التصدير إلى Excel: كل أداة على حدة، والمشروع كله في ملف واحد.

<a id="role-reading" data-unless="edit"></a>
## قراءة المشاريع

حسابك للقراءة. وهو مخصص لمن يتابع المشاريع دون أن يغيّرها.

- فتح **Dashboard** وقائمة **Projects** وأي مشروع.
- قراءة كل أداة. أزرار مثل **View Assessment** و**View Tool →** و**View Data** تأخذك إلى الصفحات.
- فتح وتنزيل وثائق المشروع في **Documents** ووثائق **Library**.

لا يستطيع حسابك إنشاء شيء أو تغييره، ولا رفع الملفات، ولا التصدير إلى Excel. إذا احتجت ملف Excel
فاطلبه من زميل يعمل على المشروع.

<a id="role-overview" data-requires="manage_users"></a>
## أي دور تعطي: من يفعل ماذا

عند إنشاء مستخدم أعطه الدور المناسب لعمله:

| المهمة | الأدوار |
|---|---|
| إنشاء مشروع وتعديل بياناته، وملء الأدوات وحفظها وإرسالها، ورفع الوثائق، والتصدير | Administrator، Environmental Specialist، Program Manager، Project Manager، Environmental Focal Point |
| اعتماد الأداتين 1 و2 أو رفضهما، وأرشفة المشاريع واستعادتها وحذفها، والعناية بالمكتبة | Environmental Specialist، Administrator |
| المستخدمون، والحذف النهائي، وسجل النشاط | Administrator |
| قراءة كل شيء | كل الأدوار، ومنها Viewer |

لأدوار Program Manager وProject Manager وEnvironmental Focal Point الصلاحيات نفسها حاليًا؛
وأسماؤها تدل على موقع الشخص في المؤسسة. أما **Viewer** فيقرأ فقط ولا يصدّر.
