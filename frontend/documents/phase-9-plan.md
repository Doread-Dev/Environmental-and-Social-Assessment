### معايير الاختبار

| الفحص | الوصف | الكلاس المتوقع |
|-------|-------|----------------|
| الخلفيات | خلفية الصفحة | `dark:bg-background-dark` |
| السطوح | خلفية الكروت | `dark:bg-surface-dark` أو `dark:bg-[#152a1d]` |
| النصوص | النص الرئيسي | `dark:text-white` |
| النصوص الثانوية | النص الخافت | `dark:text-gray-400` |
| الحدود | حدود الكروت والـ inputs | `dark:border-border-dark` |
| الـ Inputs | خلفية الحقول | `dark:bg-[#102216]` |
| العناصر المعطلة | الخلفية | `dark:bg-white/5` |

### أنماط مرفوضة في Dark Mode

```jsx
// ❌ لا تستخدم هذه الأنماط
dark:bg-gray-800        // استخدم dark:bg-surface-dark
dark:bg-gray-900        // استخدم dark:bg-background-dark
dark:border-gray-700    // استخدم dark:border-border-dark
```

### قائمة فحص Dark Mode لكل صفحة

```markdown
- [ ] جميع الـ inputs لها حدود مرئية
- [ ] جميع الأزرار مرئية وقابلة للنقر

- [ ] مؤشرات التحميل مرئية

- [ ] الانتقالات سلسة
```

### اختبار التبديل بين الأوضاع

1. افتح الصفحة في الوضع الفاتح
2. انتقل لجميع أقسام الصفحة
3. بدّل إلى الوضع المظلم
4. تحقق من جميع العناصر
5. بدّل مرة أخرى للوضع الفاتح
6. تأكد من عدم وجود مشاكل بصرية

## 📝 المرحلة 9.5: اختبار التنقل بلوحة المفاتيح

### سلوك المفاتيح المتوقع

| المفتاح | السلوك المتوقع |
|---------|----------------|
| `Tab` | التنقل للعنصر التفاعلي التالي |
| `Shift+Tab` | التنقل للعنصر السابق |
| `Enter` | تفعيل الأزرار/الروابط |
| `Space` | تبديل Checkboxes/Radio |
| `Escape` | إغلاق Modals/Dropdowns |
| `Arrow keys` | التنقل داخل المكونات |

### المكونات للاختبار

```markdown
## اختبار لوحة المفاتيح

### مكونات التنقل
- [ ] MainSidebar - Tab يتنقل بين الروابط
- [ ] ProjectSidebar - Tab يتنقل بين أدوات Workflow
- [ ] MobileMenu - يفتح بـ Enter، يغلق بـ Escape
- [ ] Breadcrumb - Tab يتنقل بين الروابط

### مكونات النماذج
- [ ] Input - يمكن التركيز عليه والكتابة
- [ ] Textarea - يمكن التركيز عليه والكتابة
- [ ] Select - يفتح بـ Enter، التنقل بـ Arrows
- [ ] Checkbox - يتبدل بـ Space
- [ ] RadioGroup - التنقل بـ Arrow keys
- [ ] Button - يفعّل بـ Enter أو Space

### مكونات التفاعل
- [ ] Modal - يفتح ويغلق بشكل صحيح، الـ focus محصور
- [ ] Dropdown - يفتح بـ Enter، يغلق بـ Escape
- [ ] Accordion - يتوسع بـ Enter أو Space
- [ ] Tooltip - يظهر عند التركيز (اختياري)
- [ ] Pagination - Tab يتنقل بين الأزرار
- [ ] Table - Tab يتنقل للعناصر التفاعلية
```

### اختبار Focus Trap في Modals

```
1. افتح Modal
2. اضغط Tab حتى نهاية المحتوى
3. تأكد أن التركيز يعود للبداية
4. اضغط Shift+Tab
5. تأكد أن التركيز يذهب للنهاية
6. اضغط Escape
7. تأكد أن Modal يغلق والتركيز يعود للعنصر السابق
```
