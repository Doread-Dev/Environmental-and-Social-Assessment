# The Library and Guidance

The **Library** holds the organisation's guidance documents, the same for every project (for
example the environmental guidelines and the annexes). Project files do not belong here; they are
in each project's [Documents](04-projects.md#project-documents).

<a id="library-read"></a>
## Read the Library

1. Open **Library** in the left menu.
2. Search with **Search title or description**, or choose a tool in the place filter (**All
   places** shows everything).
3. **Open** reads the PDF inside ESMS, without leaving the page. The download icon saves it.

<a id="guidance"></a>
## Guidance on a tool page

Library documents can be linked to a tool. When a tool has guidance, its page shows the
**Guidance** button in the top bar, with the number of documents, for example "Guidance (2)".

1. Press **Guidance**. A side panel opens with the documents for this tool.
2. Click a document to read it. You stay on the tool page, and nothing you typed is lost.

No button means no guidance has been linked to that tool yet.

<a id="library-manage" data-requires="manage_library"></a>
## Keep the Library

### Upload a document

1. **Library** → **Upload document**. The dialog **Upload to the library** opens.
2. **Choose PDF**: the Library takes PDF files only.
3. **Title** (required), **Description** (optional: what the document is for).
4. **Order**: a whole number. Lower numbers come first; documents with the same number are sorted
   by title.
5. **Show in**: tick the tools whose **Guidance** button should show this document. Tick
   **General — Library only** for a document that appears in the Library only. Places marked v3
   belong to modules that open in v3; you can already link documents to them.
6. Press **Upload**.

### Edit, replace or delete

Each document in the list has icons next to **Open**:

- the pencil (**Edit library document**) changes the title, the description, the order and the
  places;
- the replace icon puts a new PDF in place of the old one (same title and places);
- the bin (**Delete library document**) removes it, after asking.

Replacing and deleting are written in the Activity log.
