# Tool 5 – Monitoring

Monitoring records how the environmental and social indicators develop during the project: a
baseline before the work starts, then a value for each of the four quarters. Like Tools 3 and 4,
monitoring is saved, not submitted or approved, and stays editable.

Tool 5 opens when Tools 3 and 4 are both complete (at least one row each, every row with its
description; see [Tools 3 and 4](07-tools-3-4-semp.md#semp-complete)). Until then the page shows
**Monitoring Locked**; **Go to SEMP** takes you to Tools 3 and 4.

<a id="monitoring-overview"></a>
## The monitoring overview

Open **Monitoring – Tool 5** in the project's left menu. The page **Environmental & Social
Monitoring** shows:

- **Completion Status**: whether the baseline is **Entered** or **Not Entered**, and the
  **Number of quarters recorded**;
- **Monitoring Timeline**: **Baseline**, **Quarter 1** to **Quarter 4**, marked as they are
  filled in;
- **Monitoring Scope Summary**: one card per indicator category, with the highest ranking given in
  it. Click a card to open that category in the data entry page.

**Enter / Edit Data** opens the data entry page (a read-only account sees **View Data**).

<a id="monitoring-data-entry" data-requires="edit"></a>
## Enter monitoring data

1. Press **Enter / Edit Data**. The page **Monitoring Data Entry** lists the indicator categories.
   Each one shows its **Current Ranking:**. Click a category to open it.
2. For each indicator (**Indicator Definition**, with its **Measurement** unit), fill in what you
   have:
   - **Baseline**, then **Q1**, **Q2**, **Q3**, **Q4**: the measured values. They are free text:
     write numbers, words or both.
   - **Total**: free text as well; ESMS does not add the quarters up.
   - **Final Assessment**: your conclusion for this indicator.
   - **Ranking**: **Negligible**, **Low**, **Medium**, **High** or **N/A**. The list explains what
     each level means for that indicator.
   - **Responsibility**: an **Internal user** or an **External party**, as in Tools 3 and 4.
   - **Note**: anything else.
3. Press **Save** (top right). The button shows **Saved** when it is done.

You do not need to fill in everything at once. Come back each quarter, add the new values and
save. **Cancel** goes back to the overview; if you have unsaved values, ESMS asks first (see
[unsaved changes](11-everyday-situations.md#unsaved-changes)).

<a id="monitoring-reading" data-unless="edit"></a>
## Read the monitoring data

**View Data** opens the same table, read-only. To leave it, use the project's left menu.

<a id="monitoring-complete"></a>
## When is monitoring complete?

- Monitoring is **In Progress** as soon as anything is saved, a baseline alone included.
- It is **Completed** once at least one indicator has all four quarters filled in. When the reviews
  are approved and Tools 3 and 4 are complete too, the project's status becomes **Completed**.

<a id="monitoring-export" data-requires="export"></a>
## Export

**Export Excel** is on the monitoring overview and in the top bar of the data entry page. As in
Tools 3 and 4, an export with unsaved values asks **You have unsaved changes** first: **Save and
export** or **Cancel**.
