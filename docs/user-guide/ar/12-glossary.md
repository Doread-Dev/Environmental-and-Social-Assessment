# مسرد المصطلحات

<a id="glossary-terms"></a>
## كلمات يستخدمها ESMS

| الكلمة | المعنى |
|---|---|
| **ESMS** | نظام الإدارة البيئية والاجتماعية (Environmental and Social Management System): هذا التطبيق. يقود المشروع عبر العناية الواجبة البيئية والاجتماعية لمؤسسة الآغا خان في سوريا، من الفرز الأول حتى الرصد. |
| AKF | مؤسسة الآغا خان. تستخدم ملفات التصدير من ESMS تنسيق AKF. |
| الأداة 1 – **Screening** | الفرز: النظرة الأولى على المشروع، وفئة مخاطره (من A إلى F)، وآثاره السلبية والإيجابية المحتملة. يرسله فريق المشروع، ويعتمده المراجِع أو يرفضه. |
| الأداة 2 – **Assessment** | التقييم البيئي الخاص بالموقع: المشروع وبيئته، والمتطلبات القانونية، والأساليب والمشاورات المستخدمة، ودرجات خمسين سؤالًا عن الآثار. يُرسَل ويُراجَع مثل الفرز. |
| **SEMP** | خطة الإدارة الاجتماعية والبيئية: ما سيفعله المشروع إزاء آثاره. وهي في ESMS الأداتان 3 و4. |
| الأداة 3 – **Management Activities** | أنشطة الإدارة البيئية والاجتماعية العامة للمشروع. |
| الأداة 4 – خطة التخفيف | التدابير المحددة التي تقلل كل خطر أو تزيد كل فائدة (**Impact Mitigation & Enhancement Plan**). |
| الأداة 5 – **Monitoring** | الرصد: قيم المؤشرات البيئية والاجتماعية، أي خط الأساس وأربعة أرباع. |
| فئة المخاطر | نتيجة الفرز: A **High Risk**، B **Low-Moderate Risk**، C **Negligible Risk**، D **Emergency**، E **Insufficient Info**، F **Positive Impact**. |
| مستوى الأثر | درجة سؤال أو مؤشر: **Negligible** أو **Low** أو **Medium** أو **High** أو **N/A** (لا ينطبق). |
| **Total Project Impact** | الأثر الكلي للمشروع: أعلى مستوى أثر وُجد في تقدير التقييم. |
| خط الأساس | قيمة المؤشر قبل بدء أعمال المشروع. |
| المحرِّر | مستخدم يُدخل البيانات: Program Manager وProject Manager وEnvironmental Focal Point وEnvironmental Specialist وAdministrator. |
| المراجِع | مستخدم يعتمد الأداتين 1 و2 أو يرفضهما: Environmental Specialist وAdministrator. |
| مسودة | محفوظ ولم يُرسَل بعد؛ ما يزال قابلًا للتعديل. |
| الإرسال | إرسال الأداة 1 أو 2 إلى المراجِع. وتُقفل ما دامت تنتظر. |
| الاعتماد | قبول أداة مرسَلة. تصبح نهائية وتُفتح الأداة التالية. والتوصيات مطلوبة. |
| الرفض | إعادة أداة مرسَلة إلى الفريق مع السبب، لتصحيحها وإرسالها من جديد. |
| الأرشفة | حفظ المشروع للقراءة فقط وإخراجه من قائمة المشاريع. ويمكن استعادته. |
| **Library** | المكتبة: ملفات PDF الإرشادية للمؤسسة، وهي واحدة لكل المشاريع. |
| **Guidance** | الزر في صفحة الأداة الذي يفتح وثائق المكتبة المرتبطة بتلك الأداة. |
| **Documents** | ملفات المشروع الخاصة، مصنّفة حسب الأداة. |
| v3 | الإصدار القادم من ESMS. والأزرار التي عليها **Available in v3** تخصه. |
