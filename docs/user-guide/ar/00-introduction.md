# حول هذا الدليل

هذا الدليل موجّه إلى مستخدمي ESMS، نظام الإدارة البيئية والاجتماعية لمؤسسة الآغا خان – سوريا. وهو
يصف الإصدار 2.0.0 من النظام.

يعرض لك الدليل الأقسام التي تناسب دورك فقط: أي إنك تقرأ عمّا يمكنك فعله في ESMS لا غير.

<a id="how-to-read"></a>
## كيف تقرأ هذا الدليل

- ابدأ بـ [البداية السريعة](01-quick-start.md)، وهي صفحة واحدة.
- ثم اقرأ الجزء الذي تحتاجه عندما تحتاجه. كل جزء قائم بذاته.
- الكلمات المكتوبة بخط عريض (مثل **Save**) هي ما تراه في التطبيق حرفيًا: اسم زر أو قائمة أو حقل
  أو صفحة. وهي بالإنجليزية لأن واجهة التطبيق بالإنجليزية. ابحث عنها على الشاشة.
- يفتح **Help** في القائمة الجانبية هذا الدليل. وفي صفحة الأداة يفتحه زر **Help** في الشريط العلوي
  عند تلك الأداة. ويبدّل **English** و**العربية** في الأعلى اللغة، ويطبعه **Print** (أو يحفظه بصيغة
  PDF).

<a id="the-workflow"></a>
## مسار العمل

يمرّ كل مشروع بالأدوات الخمس نفسها، وبهذا الترتيب. ولا تُفتح أداة إلا بعد إنجاز الأداة التي قبلها.

1. الفرز (الأداة 1): نظرة أولى على المشروع وفئة مخاطره. يُرسَل للمراجعة، ثم يُعتمد أو يُرفض.
2. التقييم (الأداة 2): التقييم البيئي الخاص بموقع المشروع. يُرسَل للمراجعة، ثم يُعتمد أو يُرفض.
3. الأداتان 3 و4 (خطة الإدارة SEMP): أنشطة الإدارة وخطة التخفيف. تُحفظ ولا تحتاج إلى اعتماد.
4. الأداة 5 (الرصد): خط الأساس وبيانات الرصد لأربعة أرباع. تُحفظ ولا تحتاج إلى اعتماد.

اعتماد الفرز ← اعتماد التقييم ← اكتمال الأداتين 3 و4 ← الرصد.

<a id="words"></a>
## كلمتان يستخدمهما هذا الدليل

- المحرِّر: مستخدم يستطيع إدخال البيانات وتعديلها، وهو: Program Manager وProject Manager
  وEnvironmental Focal Point وEnvironmental Specialist وAdministrator.
- المراجِع: مستخدم يعتمد الأداتين 1 و2 أو يرفضهما، وهو: Environmental Specialist وAdministrator.
