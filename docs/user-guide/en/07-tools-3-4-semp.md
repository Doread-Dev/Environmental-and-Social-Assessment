# Tools 3 and 4 – SEMP

The SEMP (Social and Environmental Management Plan) is what the project will do about the impacts
found in the assessment. In ESMS it is two tables:

- Tool 3, **Management Activities**: general environmental and social management activities for
  the project's life (for example stakeholder engagement, capacity building).
- Tool 4, the mitigation plan: the specific measures for each identified risk.

Tools 3 and 4 open when the assessment is approved. They are not submitted or approved: they are
saved and stay editable. Tool 5 opens when both are complete.

<a id="semp-overview"></a>
## The SEMP overview

Open **SEMP – Tools 3 & 4** in the project's left menu. The page **Environmental & Social
Management Plan** shows, under **Management Tools**, one card per tool:

- **Management Activities** (Tool 3) and **Management & Mitigation** (Tool 4);
- the tool's status: **Not Started**, **In Progress** or **Completed**;
- the button that opens it: **Start Tool →**, **Continue Editing** or **Review & Edit**; for a
  read-only account, **View Tool →**.

Below them, **SEMP Plan** is a grey card marked **Available in v3** (see
[locked buttons](11-everyday-situations.md#v3-buttons)).

While the assessment is not approved, the page shows **Tools Locked** and **Go to Assessment**.

<a id="semp-tables" data-requires="edit"></a>
## Working in a table

The tool pages use the full width of the screen. The top bar has the back arrow (**Back to
Overview**) and the **Guidance** button when guidance exists. On a phone or a small tablet, the
menu button (three lines) at the top left opens the project's menu.

- The table starts with one empty row. Click a cell to type in it.
- **Add another row** (under the table) adds a row.
- To remove a row, move the mouse over it: a red × appears at the right end of the row
  (**Delete Row**). Click it.
- **Responsibility**: first choose **Internal user** (a person in ESMS: pick them from the list) or
  **External party** (type the name, for example "Contractor" or "Municipality"). One or the other,
  never both.
- Press **Save** (top right) to save the whole table. The button shows **Saving...**, then
  **Saved**. Until you save, nothing is stored: if you leave with changes, ESMS asks first (see
  [unsaved changes](11-everyday-situations.md#unsaved-changes)).
- Rows you removed are deleted when you press **Save**. The Activity log records how many rows were
  removed and what they contained.
- **Back** returns to the SEMP overview.

<a id="management"></a>
## Tool 3 – Management activities

Page title: **Environmental & Social Management**. One row per activity:

| Column | What it holds |
|---|---|
| **Activity Description** | the activity (required for the tool to be complete) |
| **Potential Impact / Risk** | the impact or risk the activity deals with |
| **Recommended Action Items** | what should be done |
| **Monitoring Requirements** | how it will be checked |
| **Responsibility** | an internal user or an external party |
| **Notes** | anything else |

<a id="mitigation"></a>
## Tool 4 – Mitigation plan

Page title: **Impact Mitigation & Enhancement Plan**. One row per output or activity:

| Column | What it holds |
|---|---|
| **Output / Activity Description** | the output or activity (required for the tool to be complete) |
| **Potential Impact - Significance/Risk** | the impact and how significant it is |
| **Mitigation & Enhancement measures** | the measures to reduce harm or increase benefits |
| **Monitoring** | how the measures will be monitored |
| **Responsibility** | an internal user or an external party |
| **Schedule** | when |
| **Notes** | anything else |

<a id="semp-complete"></a>
## When are Tools 3 and 4 complete?

Each tool is **Completed** when it has at least one row and every row has its description
(**Activity Description** in Tool 3, **Output / Activity Description** in Tool 4). The other
columns may stay empty.

When both are complete, Tool 5 (monitoring) opens. If later a table loses its last row, or a row
loses its description, Tool 5 locks again until both tables are complete again; the monitoring data
already entered is kept.

<a id="semp-export" data-requires="export"></a>
## Export

**Export Excel** in the top bar downloads the tool you are on, in the AKF layout.

- If the table has changes that are not saved, ESMS asks **You have unsaved changes**: **Save and
  export** saves first and then exports; **Cancel** exports nothing.
- If nothing has been saved yet, ESMS offers **Export an empty template**: press **Export** to get
  the empty sheet.
