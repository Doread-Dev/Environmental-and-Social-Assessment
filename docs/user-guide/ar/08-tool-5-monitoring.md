# الأداة 5 – الرصد

يسجّل الرصد تطوّر المؤشرات البيئية والاجتماعية خلال المشروع: خط أساس قبل بدء العمل، ثم قيمة لكل
ربع من الأرباع الأربعة. والرصد، مثل الأداتين 3 و4، يُحفظ ولا يُرسَل ولا يُعتمد، ويبقى قابلًا
للتعديل.

تُفتح الأداة 5 عند اكتمال الأداتين 3 و4 كلتيهما (سطر واحد على الأقل في كل منهما، ولكل سطر وصفه؛
انظر [الأداتان 3 و4](07-tools-3-4-semp.md#semp-complete)). وقبل ذلك تعرض الصفحة **Monitoring Locked**
وتوجّهك إلى الأداتين 3 و4.

<a id="monitoring-overview"></a>
## صفحة الرصد

افتح **Monitoring – Tool 5** من القائمة الجانبية للمشروع. تعرض صفحة **Environmental & Social
Monitoring**:

- **Completion Status**: هل خط الأساس **Entered** أم **Not Entered**، و**Number of quarters
  recorded**؛
- **Monitoring Timeline**: **Baseline** ثم **Quarter 1** حتى **Quarter 4**، ويُعلَّم كل منها عند
  ملئه؛
- **Monitoring Scope Summary**: بطاقة لكل فئة مؤشرات، مع أعلى تصنيف أُعطي فيها. اضغط على بطاقة لتفتح
  تلك الفئة في صفحة إدخال البيانات.

يفتح **Enter / Edit Data** صفحة إدخال البيانات (ويرى حساب القراءة فقط **View Data**).

<a id="monitoring-data-entry" data-requires="edit"></a>
## إدخال بيانات الرصد

1. اضغط **Enter / Edit Data**. تعرض صفحة **Monitoring Data Entry** فئات المؤشرات، وتُظهر كل فئة
   **Current Ranking:**. اضغط على فئة لفتحها.
2. لكل مؤشر (**Indicator Definition** مع وحدة القياس **Measurement**) املأ ما لديك:
   - **Baseline** ثم **Q1** و**Q2** و**Q3** و**Q4**: القيم المقيسة. وهي نص حر: اكتب أرقامًا أو
     كلمات أو كليهما.
   - **Total**: نص حر أيضًا؛ ولا يجمع ESMS الأرباع.
   - **Final Assessment**: خلاصتك لهذا المؤشر.
   - **Ranking**: **Negligible** أو **Low** أو **Medium** أو **High** أو **N/A**. وتشرح القائمة ما
     يعنيه كل مستوى لذلك المؤشر.
   - **Responsibility**: **Internal user** أو **External party**، كما في الأداتين 3 و4.
   - **Note**: أي شيء آخر.
3. اضغط **Save** (أعلى اليمين). يُظهر الزر **Saved** عند الانتهاء.

لا يلزم ملء كل شيء دفعة واحدة. عُد كل ربع سنة، وأضف القيم الجديدة، واحفظ. ويعيدك **Cancel** إلى
صفحة الرصد؛ وإذا كانت لديك قيم غير محفوظة يسألك ESMS أولًا (انظر
[التغييرات غير المحفوظة](11-everyday-situations.md#unsaved-changes)).

<a id="monitoring-reading" data-unless="edit"></a>
## قراءة بيانات الرصد

يفتح **View Data** الجدول نفسه للقراءة فقط. وللخروج منه استخدم القائمة الجانبية للمشروع.

<a id="monitoring-complete"></a>
## متى يكتمل الرصد؟

- يكون الرصد **In Progress** بمجرد حفظ أي شيء، ولو كان خط الأساس وحده.
- ويكون **Completed** عندما يكون لمؤشر واحد على الأقل أرباعه الأربعة مملوءة. وإذا كانت المراجعتان
  معتمدتين والأداتان 3 و4 مكتملتين أيضًا، تصبح حالة المشروع **Completed**.

<a id="monitoring-export" data-requires="export"></a>
## التصدير

يوجد **Export Excel** في صفحة الرصد وفي الشريط العلوي لصفحة إدخال البيانات. وكما في الأداتين 3 و4،
يسألك التصدير مع قيم غير محفوظة أولًا **You have unsaved changes**: **Save and export** أو
**Cancel**.
